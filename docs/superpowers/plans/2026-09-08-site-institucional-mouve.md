# Site Institucional Mouve — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the static Mouve Creative institutional site (5 pages) as a Next.js + TypeScript + Tailwind + shadcn/ui project, deployable to Vercel with zero backend.

**Architecture:** Next.js App Router, one route per page, content written directly in each page component. A single pure function (`lib/whatsapp.ts`) builds every WhatsApp CTA link. Shared chrome (`Nav`, `Footer`) and content primitives (`SectionHeading`, `PlanCard`, `MethodStep`) live in `components/`. No database, no API routes, no auth.

**Tech Stack:** Next.js 14 (App Router), TypeScript, Tailwind CSS, shadcn/ui (Button, Card), Vitest + React Testing Library for tests, Poppins (Google Fonts) for all typography.

## Global Constraints

- Brand colors, exact hex: azul `#0F0FDF`, grafite `#16181F`, paper `#F6F4EF`. No gradients.
- Typography: Poppins for every heading/body/label — no other font family anywhere.
- No em dash (`—`) in any copy, anywhere in the site.
- `/planos` never renders a currency value (`R$` or any digit sequence formatted as money) — plans show scope, not price.
- Footer contains no long-form paragraph text — logo, nav links, WhatsApp link, social link only.
- Every contact CTA is a `wa.me` link built by `lib/whatsapp.ts` — no `<form>`, no `mailto:`, no third-party form service.
- Mouve's real WhatsApp number is not known yet — it is read from `NEXT_PUBLIC_MOUVE_WHATSAPP`, never hardcoded, and `.env.example` documents it with an obvious placeholder value.

Create `lib/whatsapp.ts`:

```ts
export function buildWhatsAppUrl(message: string): string {
  const number = process.env.NEXT_PUBLIC_MOUVE_WHATSAPP;
  if (!number) {
    throw new Error(
      "NEXT_PUBLIC_MOUVE_WHATSAPP não está configurado (.env.local)."
    );
  }
  return `https://wa.me/${number}?text=${encodeURIComponent(message)}`;
}
```

  return (

}
